    l0.DependencyControl.ModuleProvider¶

    ModuleProvider = require "l0.DependencyControl.ModuleProvider"

    local ModuleProvider = require("l0.DependencyControl.ModuleProvider")

    ModuleProvider ¶

    Resolves provided module aliases to their provider module through a custom package searcher.

    runInitializer ¶

    ModuleProvider.runInitializer ref, DependencyControl

    ModuleProvider.runInitializer(ref, DependencyControl)

    Runs a freshly-loaded module reference's DependencyControl initializer (__depCtrlInit), if it has one and hasn't been initialized yet, so the module exposes a proper DependencyControl record. The guard avoids re-initializing modules that mutate state on first init (e.g. BadMutex).

    param type description
    ref any The loaded module reference.
    DependencyControl table The DependencyControl class handed to the initializer.

    Returns:

    • ran boolean|nil — True if the initializer ran, false if there was nothing to run, nil on initializer error.
    • err string? — Error message when the initializer raised.

    fullTraceback ¶

    ModuleProvider.fullTraceback msg

    ModuleProvider.fullTraceback(msg)

    Builds a stack traceback string with full, untruncated source paths, rewriting known Aegisub directory prefixes back to their ?user/?data/?temp aliases. Suitable as an xpcall handler.

    param type description
    msg? string A message, typically the error, prepended to the traceback.

    Returns:

    • traceback string — The formatted traceback, one frame per line.
