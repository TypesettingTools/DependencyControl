# DependencyControl

Dependency manager, automatic script updater, and module framework for Aegisub macros and modules.

This site collects DependencyControl's design notes and the generated API reference. For installation and usage guides, see the [project README](https://github.com/TypesettingTools/DependencyControl).

- **[API Reference](reference/index.md)** — generated documentation for every module: classes, methods, parameters, and types.
- **[Updater Architecture](design/updater-architecture.md)** — how trust-aware source selection and package updates work.
